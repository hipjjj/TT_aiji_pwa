# 小包的本地营养数据

## 基础食材

使用 USDA National Nutrient Database for Standard Reference Release 28（SR28）公开营养事实，来自固定版本的开源镜像：

- USDA 官方入口：https://fdc.nal.usda.gov/
- 镜像：https://github.com/alyssaq/usda-sqlite
- 固定提交：`1e457b599af101ce463a195867574eba16c81acb`
- 数据文件 SHA-256：`ae4800c3f718bb51358b860b5ec61d0ded5572522a274cb40e7cabe9aee5544d`
- 本地导入脚本会核对校验和与 SQLite 完整性。
- 热量使用营养项208（kcal），蛋白质203、碳水205、脂肪204（g），均为每100克可食部分。

中文名称与别名在 `scripts/food-mappings.tsv` 人工对应到原记录，生成后的每条数据保留原英文描述和 SR28 编号。生熟、去皮、去壳等状态见食物名称。USDA 数据不是中国餐馆的实测数据，品牌和做法不同会有差异。

## 份量与参考中餐配方

115项记录中有25个参考配方。这些值由列明的食材营养、参考用量和出品重量换算，不是 AI 编造，也不是对实际餐馆菜品的精确测量。配方与出品重量随条目保存，界面可以展开查看。油量、调料、含水量和原料比例需要用户确认；未列出的调料不在计算中。

碗、杯、片、个等重量是界面参考份量，不冒充 USDA 标准测量；液体的毫升按约1毫升=1克处理并明确提示。应优先使用实际可食重量。默认“鸡胸肉”对应熟去皮参考；生鸡胸肉是单独条目。菜品标签均注明“参考配方”。

复现生成数据：

```sh
python3 scripts/build-food-library.py
# 或复用已下载且通过校验的文件：
python3 scripts/build-food-library.py /path/to/usda.sql3
```

菜品换算使用十进制四舍五入到每100克两位小数。保存饮食时保存当时的营养快照，之后更新字典不会改写历史记录。

## 营养目标

成年人的基础代谢采用 Mifflin–St Jeor 公式：男性参数 `10×kg + 6.25×cm − 5×age + 5`，女性参数末项为 `−161`。来源：Mifflin et al., 1990, PMID 2305711，https://pubmed.ncbi.nlm.nih.gov/2305711/ 。

活动量乘数1.2、1.375、1.55、1.725、1.9是常用活动量估算分级，不能精确测量个人消耗。维持目标使用估算消耗，减脂取约85%，增重约110%；自动热量起点不低于男性1500、女性1200 kcal。蛋白质起点维持取1.2g/kg，减脂/增重取1.6g/kg；脂肪按热量25%估算，碳水使用余量。营养素建议范围为起点约±10%，热量下限同时受上述起点下限约束。

这些是产品中明确展示、可调整的经验规则，不是公式原论文规定的医学处方。低体重情况下不提供通用减脂目标，18岁以下不使用自动计算。妊娠、哺乳及特殊疾病饮食不在自动建议适用范围；用户可根据专业建议设置允许范围内的手动目标。历史趋势按当前目标对照，未记录日期不会被当作零摄入加入平均值。
