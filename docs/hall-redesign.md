# 企鹅家族大厅改版

原部署入口为 https://hipjjj.github.io/TT_aiji_pwa/ ，仍使用既有 Pages 工作流和 `/TT_aiji_pwa/` base。PWA 名称、start_url、scope 和原图标文件地址保留。

首页六个圆形入口为记账、吃饭小屋、旅行册、备课室、学习室、个人。中央进入企鹅小家。营养、库存、食谱和购物共用吃饭小屋。备课室复用既有试卷批阅，不提供教学进度。

角色与用户提供的角色表、手机界面图统一：鲍比、小包、嘟嘟糕、黏黏包为四只等大的大企鹅；邪恶包、羊羊包为两只等大的小企鹅，只有羊羊包为女生。彪彪仍是个人页的海鸥。角色 atlas、群像和页面均使用本地 WebP，随 PWA 离线缓存。聊天扩展到六名角色，需同步部署 Worker 的角色枚举与人格说明。

学习室提供自写的企鹅科普示例、粘贴或 TXT 文章导入、常见词简明离线释义、手填释义、生词收藏及掌握标记、阅读足迹。支持本机提取文字型PDF和通过既有后端读取公开网页URL。PDF上限12MB/200页，扫描件需先OCR；网页提取沿用个人页已保存的后端地址和访问口令，不调用OpenAI且使用独立限额。需要登录、依赖脚本或拒绝自动读取的网站可能无法导入。提取结果均先展示为可编辑草稿，保存后可离线阅读。

## 数据兼容

`src/db.ts` 未修改：数据库名称 `riri-expenses`、v1–v11迁移、全部21张表及索引保留。原记录ID、日期、照片 data URL、关联账单和照片字段均保持。新学习资料使用现有 appMeta 表中的独立 `study-state` 行，不增加或重建数据库。

备份仍是 version:1。可选 study 部分包含文章、生词和阅读足迹；原全量和分模块备份继续导入，未携带 study 的旧备份不会清除本机学习资料。单模块饮食与冰箱备份仅更新显示名称，范围标识 nutrition/fridge 保持，旧备份仍兼容。API设置和访问口令不进入备份。
