# 旅行册数据与行为

## 行政区地图

- 原始来源：阿里云 DataV.GeoAtlas。使用 [zhChuXiao/ChinaGeoJson](https://github.com/zhChuXiao/ChinaGeoJson) 开源镜像，固定提交 `7aa2c5fabc6a892015625898c3482874b233f9de`（2026-08-10），MIT，原许可见 `docs/licenses/travel-map-MIT.txt`。
- 34个省级区域、370个用于旅行记录的区域。普通省份包括地级市、自治州/地区以及数据源中的省直辖县级区域；北京、天津、上海、重庆、香港、澳门按整体记录，不把下辖区计作地级市。台湾数据源只提供整体边界，界面明确说明，不编造地级细分。
- 全国省边界由省内区域共享拓扑合并而来；结果精度归一到6位小数，不抽稀城市原始边界。全国轮廓及南海诸岛来自同一来源。地图为旅行足迹界面，非导航、非实时行政区数据；不宣称拥有另外的审图批准号。
- 全国和省内城市替换同一个 SVG 地图区域，点城市后打开景点/记录弹窗，点击“全国”返回。南海诸岛是同一 SVG 的静态地图插图，不是第二个省级导航地图。
- 首次联网后，34份省地图及全国地图会随 PWA 缓存，之后未打开过的省份也可离线查看；地图总数据约5 MB，加其他资源总缓存约6 MB。

## 景区名录与覆盖边界

- 接入 [LoreRoutes / china-5a-scenic-areas](https://github.com/tuansuwu/china-5a-scenic-areas) 的373条5A名录快照，固定提交 `49e335839bdea082c9e9e8e887d8d9ec574e9306`（2026-08-31）。来源是第三方整理的快照，不保证当前官方评级或完整性；界面保留逐条来源链接与日期。
- 原数据与本项目改编后的 `src/travel/scenic.json` 按 **CC BY-SA 4.0** 发布，原许可见 `docs/licenses/travel-scenic-5A-CC-BY-SA-4.0.txt`。改编仅提取中文名称、评级、城市归属和来源字段，按本项目行政区代码匹配。
- 4条原来源只给省级归属的记录做了明确城市归属补充：槟榔谷与呀诺达映射保亭 `469029`，分界洲岛映射陵水 `469028`，塔克拉玛干·三五九旅映射阿拉尔 `659002`。全部373条可匹配到旅行区域。
- 景点列表仅提供5A名录与其他地点。自填景点/评级独立存储，显示“用户补充 · 评级待核实”；即使填写来源链接，也不会自动视为官方认证。旧记录中已退役的评级分类迁入“其他”，景点名称、旅行日期、照片和游记保留；旧备份导入使用相同归类规则。
- 景区评级和归属会变动，以主管部门最新公布为准。名录空白城市也能手动填写去过的地点。

## 本地记录、点亮与照片

- 一段旅行包含1–20个城市、每城最多40个地点、最多12张照片。支持起止日期、感受、游记及照片说明。
- 去过状态为“结束日期已到的旅行城市”与“手动标记城市”的并集。未来日期旅程可先保存，到完成日期才计入点亮。删除旅行只重新计算自动点亮，不删除独立手动标记。
- 照片仅当前设备保存，支持JPEG/PNG/WebP，每张上传不超过10 MB，最长边压缩至960px并转JPEG，不保留原照片EXIF。点击照片可放大查看。
- 本地“黏黏包整理游记”仅以已有日期、城市、景点和感受拼接模板，不调用AI，也不添加未记录的天气或事件。AI只在主动勾选同意并点击后发送本次旅行文字，不发送照片或其他模块数据，草稿需要确认后保存。
- 完整备份包含旅行、照片、游记、手动足迹和自填景点。按编号合并；旧备份没有travel字段则不修改现有旅行资料。无照片备份省略图片，导入时保留本机已有同编号旅行的照片；新设备无法恢复省略的照片。所有模块在同一事务写入，损坏旅行不会导致部分财务导入。

## 重新生成固定快照

从仓库根目录运行：

```sh
npm ci
python scripts/download-travel-data.py /tmp/tt-travel-source
node scripts/build-travel-data.mjs /tmp/tt-travel-source
npm test
```

下载器使用HTTPS并校验保存在 `scripts/travel-source/` 的SHA256；不会接受不同文件或自动刷新到未审核的新版本。普通安装和构建使用已提交的生成文件，不需要重新下载地图。
