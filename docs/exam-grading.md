# 邪恶包和羊羊包的批改室

底部“批卷”Tab，第一版支持1–100道A–H单选题、一张试卷/答题区照片。用户提供完整标准答案，填写总题数，并逐行填写题目A（起始题号）、题目B（结束题号）、每题分数，可用Add new新增区间或删除区间。所有题目必须被覆盖一次，不设置默认分值。单题的A/B填同一题号。标准答案支持连续字母、分隔字母、带题号的答案；缺题、重号、多选格式、分值区间重叠或漏题均拒绝保存。旧版每题分值数组会合并连续相同分值，恢复为区间行；保存格式仍为原points数组，旧设置、备份与历史结果兼容。

AI只识别学生实际作答，不解题、不判断对错、不计算分数。`GRADING_MODEL` 独立默认为完整版 `gpt-5`，图片使用 `detail: high`，结构化返回题号、作答、置信度、备注。标准答案、分值、其他记录和身体资料均不发送；照片中的姓名不返回。调用沿用个人页连接、访问口令、全站每日/每分钟额度。接口 `/grade-exam` 单独允许较大照片请求，不放宽其他接口的上限。

照片本地最长边2400像素、JPEG约0.9质量，过大时分档压缩，最大约2.8MB数据URL；原图不改变，EXIF不保留。HEIC需转换，原文件上限20MB。保存时可选择保留压缩照片。只有点击“识别”才上传，选择图片本身不调用AI。

程序按整数分单位累加分数，避免浮点误差。明确空白为错误；缺失题号、模糊/中低置信度作答为“待核对”，不直接判错，显示已确定得分。用户逐题选择实际答案后重新计分，仍有待核对题时不允许确认保存。表格每段10题，上行为题号、下行为✓/✗/?，手机可横向滚动；总分及对错数另列。AI识别并不等于最终人工核对准确性。

Dexie v11新增 `gradingSettings` 与 `examGrades`。历史记录保存当时的标准答案、分值和校对状态快照，设置修改不改变旧结果。最近50条记录可查看、修改、删除；所有记录纳入备份。全量与“试卷批阅”独立备份均包含设置及记录；照片开关控制试卷照片，无照片备份在原设备恢复时保留已有同编号照片。旧备份未提供grading字段时不改动批阅资料。

新企鹅仅用于这个功能，未加入既有四只企鹅的固定聊天世界观。

## 部署与验证

前端和Worker都需部署。`Deploy Xiaobao AI backend` 在更新Worker前用公开合成答题卡（B/D/A）验证账号的GPT-5高清看图和严格JSON能力，失败则保留旧Worker。部署后检查真实 `/grade-exam` 识别及本地10/10计分，不用学生照片，不写用户数据。既有聊天看图检查保留在部署前步骤，部署后试卷识别替代重复颜色识别检查，使全套部署检查仍为5次共享额度请求。

本地浏览器流程使用可控模拟provider结果验证设置、图片处理、待核对防线、手动更正、历史和备份；这类测试不能作为真实OpenAI已联通的证据。真实模型验证必须看到部署工作流成功。
