# 学习室 PDF 与 URL 导入

文章导入提供粘贴文字、PDF/TXT文件、网页URL三种方式。读取结果展示在同一标题/正文编辑框，用户确认保存后才写入原 appMeta 的 study-state 行。

PDF由PDF.js在本机读取，不发送至后端。限制12MB、200页、10万字符，可取消读取；无文字扫描件、密码保护及损坏文件给出说明。提取按页面顺序拼接，复杂多栏布局仍需核对段落；原始PDF文件不作为附件保存。PDF读取模块延迟加载，模块及mjs解析worker随PWA缓存。

URL通过POST /study-article读取公开HTTP/HTTPS网页。沿用个人页配置的后端根地址及访问口令，不调用OpenAI。后端校验地址、逐次检查重定向，限制正文响应2MB、跳转4次、15秒超时及10万字符；仅接收HTML/纯文本，拒绝本机/私网IP字面量、账号密码、非默认端口和非网页协议。读取时不传应用访问口令、Cookie或其他用户资料给目标网站。HTML由不执行脚本的DOM解析器与Mozilla Readability提取为纯文本，不执行网页脚本。独立限额每日200次、每分钟10次，不占用原AI额度。需要登录、依赖动态脚本或拒绝自动读取的页面可能无法导入；PDF链接提示下载后用本机PDF导入。

新文章可携带可选sourceUrl字段，按原version:1学习备份导出恢复；旧文章与旧备份没有此字段时保持兼容。数据库名称、schema及其他业务记录未修改。

验证包括真实多页PDF提取、扫描件/页数/字符限制、公开URL与重定向校验、HTML正文及段落提取、错误HTTP/过大内容/PDF链接处理、端点鉴权与独立限额、旧学习备份兼容。后端发布工作流还以公开example.com验证实际URL读取，测试不写入用户记录。
