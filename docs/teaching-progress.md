# 教学进度

工作页包含“教学进度”和原有“试卷批阅”。新模块按班级管理周计划，不改变原有数据的保存方式。

## 使用流程

1. 上传资料：页面上方统一进入资料管理，导入主教材PDF、辅助清单，以及PDF／DOCX／TXT教案；确认单元、来源位置和教案覆盖课时。
2. 资料管理：按主教材单元调用AI，整合已上传教案的课堂活动、练习与课时顺序，确认后用于周计划；也可以手动编辑。
3. 学期与班级：填写学期周数、周起始日期，添加任意班级，设置课表、停补课和考试范围。
4. 学期检查：设置作业、听写和教案课时要求、启用前已完成量及截止日期。
5. 本周：生成、预览并确认计划，更新实际授课和检查任务完成数量；需要时重排后续周。
6. 学期：查看考试覆盖、检查任务明细、周安排及历史版本。

初始已讲授范围需要明确勾选；输入当前页码不会自动完成此前内容。计划中的数量与实际完成数量分别保存。

## 计算规则

- 填具体星期课表后按日期计算，停补课日期填写当天的实际课时；周课时覆盖优先。仅填写每周课时总数时，假期周需要教师确认覆盖值。
- 考试新课范围和复习安排使用考前的完整教学周，考试周只扣除指定占课数。补充的页码或章节文字显示为人工核对提示，不冒充已经理解的精确约束。
- 作业、听写、教案使用整数分配；按可用周权重分配，保持总量。截止日期前没有完整教学周时明确提示缺口。
- 课堂教学、复习和机动课时分开计算；教案课时是备课工作量，不再次占用课堂课时。
- 已有实际记录或手动锁定的周保留；已讲授的课时不重复排入，未讲完内容可移到后续周，待巩固备注带入下一可调整周。
- 作业和听写按班记录。教案可以共享同学期、同教材的实际数量，避免跨班重复累计；存在教案实际记录后保留统计范围。

## 数据与文件

数据库保持 `riri-expenses`，版本12只新增 `teachingState` 和 `teachingFiles`，不改写原21张表。教材正文、单元分析、班级校历、计划版本和实际记录保存在前者，原PDF以Blob存放在后者。

完整备份及“教学进度”独立备份包含教学数据，可另外勾选原PDF。无PDF备份仍保留已提取文字、分析及计划；本机已有原文件在恢复时保留。旧备份不含教学字段时不处理教学数据。补回PDF时用SHA-256核对原文件。

用户导入的教材不进入网站静态发布文件。AI仅接收当前选中单元及关联辅助清单的相应页面，不接收其他模块数据、学生档案或整个本地数据库。分析使用现有个人页的连接和口令，后端进行访问与配额检查，为选定页面生成原文片段编号，AI只选择编号，程序再恢复原始引文和PDF页码。部分编号未定位时保留其余内容，并明确标记为待核对建议；超时、输出截断和结果格式异常分别提示。

文字版PDF支持20MB、300页、150万字符；单次AI分析最多12万字符。扫描型PDF须先OCR。字体粗体信息尽量保留，重点词和来源差异仍需教师核对。

## 验证

- 使用用户提供的150页教材和51页清单验证实际PDF.js提取顺序，均识别出8个正文单元；辅助清单支持单元在页面中途开始，两单元可共享边界页。
- 单元测试覆盖整数分配、停补课与周覆盖、考试约束、课时不足、锁定与实际保留、未完成内容重排、多班与共享教案、引用核对、备份恢复和刷新持久化。
- 升级测试从原v1与有完整记录及照片的v11数据库升级，比较原表与照片字节。
- AI部署流程使用接近实际单元长度、包含弯引号及换行的合成英文资料进行真实模型预检和部署后接口验证，不使用用户教材或创建本地用户记录。

## 工作页设置与教案

教学主视图只保留“本周／学期”。上方“上传资料”统一管理教材、辅助清单和教案；“管理设置”提供学期及班级的新建、编辑、删除与恢复。保存学期或班级后自动收起设置。删除为可恢复操作，计划和实际记录保留在原数据内。初始已讲授范围支持按单元全选。普通星期课表仅周一至周五，周末临时补课仍可通过具体日期录入。

教案上传后按单元与课时范围整理，支持修改识别结果。同一单元关联教案后，可在资料管理中“AI整合教案”，核对每课时建议并保存，再生成或预览重排后续周计划。Word/TXT的文字按资料分段定位，区分于真实PDF页码；原文件可一并备份。Word使用浏览器原生解压，仅提取正文XML，不执行嵌入内容，旧DOC需转为DOCX或PDF。单次AI整合最多20课时。

## 资料删除与清空

每份主教材、辅助资料和教案均可移入“已删除内容”，从资料管理或设置管理中恢复。主教材删除后，依赖它的班级与附属资料暂时隐藏；恢复主教材后，未单独删除的关联内容重新显示。

“一键清空已删除内容”会先显示资料、学期、班级、计划版本、实际进度及教案完成记录的影响数量和关联班级，确认永久清空后才执行。清空同时移除相关原文件，状态和文件在同一事务内提交；其他模块记录和照片不参与清空。确认后若另一窗口新增删除项，旧确认失效，需要重新核对范围。共享教案统计仍被其他班级使用时保留。

清空辅助资料或教案后，已确认的教学文字保留，失效引用移除并重新映射课时引用编号，标记为待核对，避免保留无法定位的来源。
