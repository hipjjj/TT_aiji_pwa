# 学习室离线英汉词库

数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)，固定版本
`39cfb9672c0906b63569e0453c2e6abfb9ab182a`，使用仓库提供的 MIT 许可。
许可原文随应用保留在 `public/study-dictionary/LICENSE.txt`。
本库不使用牛津 API；ECDICT 的 oxford 字段只是词表标记，不代表牛津释义。

从上游 ecdict.csv 提取可点击的英文单词、带连字符单词和缩写，保存中文释义（最多300字符）、已有音标、原形。大小写合并时优先小写原词；从 exchange 中补充原库缺少的词形。共400244项，按固定哈希拆成64块，总计约26.6MB，单块不超过432KB。不承诺每项都有音标，也不添加未提供的音频或例句。

可复现生成：下载固定版本的 `ecdict.csv` 后运行：

```sh
python scripts/build-study-dictionary.py /tmp/ecdict.csv
```

上游 CSV 的 SHA-256 与条数记录在 `public/study-dictionary/manifest.json`。
生成脚本不联网、不读取或修改用户数据库。

首页不解析词库。点词时仅解析所需分块，内存最多保留4块；PWA服务工作线程在后台缓存完整词库，缓存完成后支持离线。首次下载需要联网并留在网站等待缓存完成。使用原站点子路径、原数据库和原备份格式，不新增数据库迁移。词库是应用资源，不写入用户备份。

个人生词释义优先于基础词库，补充释义不改变原编号和已掌握状态；不自动批量改写旧笔记。生词本中旧的空释义可点“补充释义”查询后保存。异步查词不会覆盖正在编辑的文字，切换单词会丢弃旧查询结果。

AI语境解释仅在点击时发送当前单词和当前段落（最多1500字符），复用个人页AI连接、既有 `/chat` 接口和共享额度，不上传整篇文章、生词本、照片、记忆或历史聊天，也不创建聊天记录。结果单独展示，可手动填入释义，点击保存后才写入生词本；取消或关闭会中止等待。

词形含义可能随语境变化；本地展示原词和原形释义，AI解释作为单独的语境参考。
